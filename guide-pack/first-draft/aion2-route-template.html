    How skill points work

    Each skill gains one level every 3 character levels after you learn it. Levels 2–4 cost 1 point, 5–7 cost 2, 8–10 cost 4; points stop at 10. Skill level 8 opens the first specialty slot. Each stop point lists the upgrades that opened since the last one, in priority order. Respec is free until Lv 31.
