## One rule that changes

The cause that repeated: **an acceptance line that no file the item owned could make pass**, twice (P6: the generator
was a no-go; P8: no item owned the shell's leftover terms). The other repeats are already fixed at their source:
dead and silent runs (#163, #168, `restart.yml`), queue idles (#171, #173), conflicts (#178).

**New rule (from 0.5 on):** before an item is queued, the planner names, for each acceptance line, the file that makes
it pass; that file is in the item's own *Files* or in an item on its *After* line, and no no-go forbids it. A check
that a later item turns green (a scan, a conformance suite, a budget) is run on `main` at planning time and every hit
gets an owner. Every 0.5 plan file (`docs/plans/0.5/`) carries this as its "Ownership check" line, and the reviewer
of the planning pass checks it.
