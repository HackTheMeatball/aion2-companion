## 2. Decisions drawn

- **Where it sits.** Phone: its own full-width row under the title and above the sticky level bar, so the first screen
  shows brand, route title, character, then (once P4 lands) `LV n` + Level up. Desktop: right end of the brand row, so
  the title block does not move. The eyebrow row (game · faction · class, Basic / Advanced) is not touched; at 390 px
  its two parts already fill the row.
- **One control, one list.** The button opens a list in place (a panel under the control, full width on a phone, 460 px
  wide on desktop). New, rename and remove open inside that panel or over it, never a separate page.
- **Label.** The button text is the label (`labelOf`, ARCHITECTURE §1) as is; long names are cut with an ellipsis and the
  accessible name carries the whole label ("Character: Zed-assassin-lvl27. Switch character").
- **Targets.** Button, rows, Rename / Remove and form buttons are ≥ 44 px; field text is 16 px (no iOS focus zoom).
- **Remove is quiet.** The warn colour marks only the Remove text and the confirmation's final button; the green and
  accent fills stay where they are today (Level up, primary actions).
- **The level bar is separate.** P4's bar stays `LV n` + Level up and holds no character control (P4 no-go: nothing
  else in the bar).

## 3. Where the name may never appear

Restated from ROADMAP 0.4 review note 5, P18 and ARCHITECTURE §1 so this mockup doesn't draw anything that breaks it. The
name (and the label built from it) appears on screen, in the control, list, form and confirmation, and inside the save.
It never appears in:

- the `localStorage` key (`companion-save-v5` stays; the slot id is random, not derived from the name);
- a file name (the export file name stays as it is);
- a URL (no `?char=Zed`, no hash);
- the *Report a problem* link;
- a log line (console, error text);
- `document.title`.

Later, for sync (0.6): the name and label travel only inside the encrypted payload.

## 4. Questions for the owner (each with a recommendation)

1. **Where does the control sit?** Recommend: phone, a row under the title; desktop, right end of the brand row (as
   drawn). Alternative: inside the eyebrow row, which crowds 390 px.
2. **Show the class picker when only the Assassin exists?** Recommend: yes, as one pre-selected row. It costs one row,
   shows the player what the character is, and the form needs no change when Gladiator ships (0.6). Alternative: hide
   it until a second class has a guide pack, and label the character "Assassin" in the preview.
3. **Is the name optional?** Recommend: yes (your 2026-10-16 decision: the label drops the name part while empty).
   Maximum 24 characters, trimmed; the hyphen separator means a name with "-" reads ambiguously, so recommend allowing it
   (the label is display only, never parsed).
4. **Duplicate names?** Recommend: allowed. The slot id is the identity, and a duplicate label is still distinguished by
   the level.
5. **Does the label's level repeat the level bar's `LV n`?** On a phone the header shows `lvl27` and the bar `LV 27`.
   Recommend: keep both. The label format is yours; the bar is the Level up control.
6. **Confirmation wording.** Drawn: title "Remove Zed-assassin-lvl27?", body "Its progress is deleted from this browser. This can't
   be undone. Your other characters stay. Export first if you want a backup.", buttons "Keep it" (first, default focus)
   and "Remove". Recommend this: the safe button comes first, it names the character, and it points to Export. P19's
   plan text is the shorter "Its progress is deleted from this browser."; the extra sentences are your call.
7. **Last character.** Recommend: no Remove is offered (drawn in `p-list-one`) rather than a disabled button with an
   explanation, which adds a line to every row.
8. **Rename inline or in the form?** Recommend: inline in the list (drawn): the field replaces nothing, it opens above
   the other rows. Empty name = no name.
9. **After removing the current character, which one is current?** Recommend: the first remaining one in list order;
   the list shows the choice.
10. **Class icons in the picker.** Recommend: none for 0.5 (no new art without your OK); add them with the Gladiator pack.
